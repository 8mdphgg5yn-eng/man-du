# 慢读 · AI 回答易读器

把中文长回答分段阅读，遇到难词停一停，随时回到原文核对。

**v0.1.0-alpha · MIT · 本机运行 · OpenAI Codex 协助开发**

Read Chinese AI answers at your own pace, with the original text kept visible.

这是早期试用版。解释和例子仍可能出错，复核也可能误拦或漏判。尚未经过实际残障人士或儿童的理解与可用性验证，不据此宣称对特定群体有效。

## 可以做什么

- 保留原文，每次阅读一段；支持调整字号、高对比和专注阅读。
- 点击有限的自编词库释义，按需使用浏览器朗读。
- 选择原句，结合所示上下文请求解释，并继续追问或举例。
- 原文、解释、假设例子、摘录条件和未知说明分列，方便核对。
- 对已覆盖复杂句使用原文条件拆解，保留“可能”、必要条件和适用范围；所有展示的 AI 解释与拆解另经模型复核。

## 开始使用

需要 **Node.js 22 或更新版本**及现代浏览器。没有第三方运行依赖，无需执行 `npm install`。

从 [Releases](https://github.com/8mdphgg5yn-eng/man-du/releases) 下载 `man-du-v0.1.0-alpha.zip` 并解压，在解压后的目录打开终端：

```sh
node start-deepseek.mjs
```

打开 <http://127.0.0.1:8770/>。保持终端运行；在终端按 Ctrl+C 停止服务。macOS 用户安装 Node.js 后也可运行 `start-deepseek.command`。

也可通过 Git 获取源码：

```sh
git clone https://github.com/8mdphgg5yn-eng/man-du.git
cd man-du
node start-deepseek.mjs
```

不配置模型也可以使用分段阅读、词库和原文对照。仅双击 `index.html` 打开时，AI 接口不可用。

## 使用 DeepSeek 解释

1. 在页面“DeepSeek 本机设置”中输入自己的 API Key，点击“应用到本次服务”。
2. 放入文字，点击“开始阅读”，选择原句或点击“使用整段”。
3. 展开“模型状态与发送范围”，查看地址和上下文，确认允许发送后点击“解释一下”。

密钥提交后从输入框清除，仅留在本机服务进程内存中；停止服务后需重新输入。应用配置不会自动发起推理，也不代表密钥已验证。项目不代为开户、登录或充值，模型费用由使用者承担。

专用配置固定向 `https://api.deepseek.com/chat/completions` 发送请求，默认 `deepseek-flash`；具体可用性由服务商决定。一次解释或追问通常两次、最多四次模型调用，整体等待上限 60 秒。失败或复核不通过时，本次候选不展示。

## 如何保留原意

未覆盖的句子由模型生成解释和例子，再由同一模型的另一请求复核。最多自动修订一次；复核格式错误最多重试一次，所有阶段合计最多四次调用。同一模型可能重复相同错误，这不是独立人工审核。

两个必要条件及出发后可能返回的句式，以及已定义的“大字说明卡阅读”“语音提示找按钮”用法，采用从所选句子提取的本地拆解。页面标明“按原文拆开的解释”；具体动作放在假设背景中，不补造实际受益或必然结果。拆解同样交给模型复核；模型拒绝时停止，不反复提交同一内容等待改判。其他物件不猜测使用方式。

引用编号由本地绑定原文和候选，空字段由本地确认；摘录条件必须逐字出现在所发上下文中。编号和字面匹配不证明语义正确，也不核查原文事实真假。

## 数据与本机边界

- 分段和词语匹配在浏览器完成，不保存阅读历史，无统计、Cookie、localStorage 或远程字体。
- 只在点击解释或追问后发送所选原文、页面预览的上下文；追问另发上一条答案和问题。复核和修订会把候选及理由发到同一模型地址。
- 上下文最多 6000、选择最多 1200 个 JavaScript UTF-16 单位，不等于 token 或字节；不默认发送整篇正文。
- 本机服务不输出正文或密钥日志，静态文件使用允许列表。密钥、环境文件、服务端代码和测试文件不会通过页面静态接口提供。
- 服务仅监听 `127.0.0.1`。这是个人本机工具，不提供公网多用户服务；不要把已配置密钥的进程通过端口转发共享。
- 本机模型地址不保证模型服务没有继续转发；浏览器朗读的联网行为取决于浏览器及系统语音服务，尚未验收。
- 停止等待会尝试取消连接，但不能撤回已经发出的内容，也不保证免除服务商已产生的费用。

详细说明见 [PRIVACY.md](PRIVACY.md)。

## 开发与测试

```sh
npm test
npm run check
```

71 项本地单元与流程检查使用固定回复、回归样例及本机模拟服务，不访问真实模型，不需要 API Key。通过不代表真实模型语义正确。真实模型观察单独记录在 `docs/evidence/`，均使用自编文本。

`node server.mjs` 启动未配置模型的通用服务；通过环境变量可配置已有模型，见 [模型配置](docs/CONFIGURATION.md)。`start-deepseek.mjs` 固定启用 DeepSeek 专用本机设置。日常启动器关闭开发诊断；开发者可按配置文档显式启用仅接受两条预置句子的诊断。
