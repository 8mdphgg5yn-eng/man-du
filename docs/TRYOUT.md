# 慢读第一轮试用提纲

目的：验证逐段阅读、词语解释和原文对照是否帮助理解。当前没有证据证明该原型改善了任何特定群体的阅读体验。

## 先选择一种使用场景

候选场景是“阅读中文 AI 长回答时容易疲劳，希望按自己的节奏阅读”。优先请愿意共同设计的成年使用者试用，再根据实际障碍决定是否面向某类残障使用者或儿童另做设置。仅靠开发者模拟，不能代表使用者需求。

本提纲是准备材料，尚未招募、联系或记录任何参与者。

## 约十五分钟的操作

全程使用页面内自编示例，无需提供个人材料。参与者随时可以停止，不要求开启朗读。

1. 自己找到开始阅读的方法，读完第一段并切到下一段。
2. 试着找到“凝结”的意思，用自己的话解释，再回到原句。
3. 找到“并不是每一朵云都会下雨”，说说这句话是否被前文改变或遗漏。
4. 调整字号或专注模式，再返回完整页面。
5. 换入第二个示例，找到“事实”和“推测”的区别，指出还需要哪些材料。

## 决定下一版做什么

看参与者具体在哪里停住、误解了什么、是否需要别人提示，不以“页面好看”或“愿意点按钮”证明阅读改善。若解释改变了原句意思，先修正解释；若主要困难是输入或操作，再调整交互。根据同一个人阅读普通文本与分段页面的体验提出下一轮问题，不由少数试用推断整个群体的效果。

本版已经提供模型接入。试用仍优先使用自编示例；如试用 AI 功能，应先明确所发文本、目的地址和费用，另行记录是否保留原文的可能性、条件和范围。
