# Alpha 验证记录

记录日期：2026-10-22。本页区分机械检查、真实模型观察与尚未完成的目标使用者验证。

## 本地检查

`npm test` 的 71 项检查使用固定回复与本机模拟接口，覆盖原文位置、引用校验、条件与范围回归、取消与超时、错误隐藏、调用预算、编号绑定、受限诊断、密钥不回传和可信引擎热更新。不调用真实模型，不需要密钥。

这些检查不能证明模型语义正确。GitHub Actions 的结果以仓库中实际运行记录为准。

## 自编文本的真实 DeepSeek 观察

| 记录 | 观察与边界 |
| --- | --- |
| [两条目标句各三次](evidence/target-acceptance.json) | 6 次均返回，12 次模型调用；人工逐项读回未发现本轮针对的可能性、必要条件和范围强化。仅是有限样本。 |
| [固定好坏对照](evidence/control-review.json) | 两条正确答案均被判一致，两条错误答案均要求修订；不能据此推断所有错误都会被识别。 |
| [新词语变体](evidence/source-variants.json) | 图书馆、语音提示均返回，保留各自来源词语与限制。 |
| [正常页面观察](evidence/normal-page-checks.json) | 两条首次解释展示；一次说明卡“再举一个例子”被拦，上一条答案保留。没有把保留的答案算作新例子。 |

记录保留实际引擎与提示摘要，来自相邻迭代，不能把不同版本混成一轮。六次目标流程后，将未知说明中的“不是已经返回”改为“并未说明已经返回”，随后正常页面复查保留了该措辞。

更广的 10 条开发回归曾出现 8 条返回、2 条拦截，也曾漏过“部分”变成“只有部分”、未说明因果变为明确否定因果，以及对必要条件前后矛盾的解释。对应已复现模式加了保守拦截；已覆盖句式改用原文条件拆解。没有把该轮回归记为全部语义通过，未覆盖句式仍存在波动。

记录只包含自编句子和假设人物。发布不包含本机凭证、个人阅读材料、开发机器路径或上级项目文件。
